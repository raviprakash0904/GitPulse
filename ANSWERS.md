"# Technical Assessment Review & Answers\n\nThis document details the architectural decisions, run guides, edge-case mitigation strategies, and review reflections for the **GitPulse** dashboard.\n\n---\n\n## 1. How to Run\n\nFollow these commands to configure and boot the application locally:\n\n```bash\n# 1. Install packages\nnpm install\n\n# 2. Configure Local API Tokens (Optional but recommended)\ncp .env.example .env.local\n# Add key: NEXT_PUBLIC_GITHUB_TOKEN=your_token\n\n# 3. Launch Development Server\nnpm run dev\n\n# 4. Compile Production Builds (For validation)\nnpm run build\nnpm run start\n```\n\n---\n\n## 2. Stack Choice Rationale\n\n* **Next.js (App Router)**: Offers a modern codebase scaffolding with standard routing. We use Client Components for chart visualizations and state controls while benefiting from Next's font optimizations and fast build cycles.\n* **TanStack React Query**: Manages query caching, query statuses (loading/success/error), and retry triggers automatically. This keeps the application responsive and isolates network states from visual components.\n* **Zustand**: Provides an ultra-lightweight, boilerplate-free state manager. We persist user settings, bookmark pins, and tokens inside `localStorage` automatically using its `persist` middleware.\n* **Recharts**: Recharts is a declarative chart framework built for React, rendering SVG charts natively.\n* **Framer Motion**: Enables smooth micro-interactions like floating button reactions and card entry stagger animations, giving the UI a premium, startup-grade quality.\n\n---\n\n## 3.
